# Groups

Each group has its own folder here, containing their game project in either
Scratch or Greenfoot.

## Structure
```
groups/
├── group-01/
│ └── Scratch/
│ └── game.sb3
├── group-02/
│ └── Greenfoot/
│ └── my-game-project/
│ ├── project.greenfoot
│ ├── package.bluej
│ └── ...
└── ...
```

## Rules

- Work only inside your own `group-XX/` folder — this avoids merge conflicts with other groups.
- If your folder doesn't exist yet, create it when you add your first file (e.g. `mkdir -p groups/group-01/Scratch`).
- For Greenfoot, keep `project.greenfoot` and `package.bluej` — these are required for the project to reopen. Compiled `.class` files are ignored by git and don't need to be committed.
- See the main [README](../README.md) for the full branching guide.
